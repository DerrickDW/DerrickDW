## Selected Work

### 📦 Warehouse Automation

Built Python and C# tooling to extract structured order data from inconsistent
warehouse PDFs using rule-based parsing, cleanup, validation, and spreadsheet
generation.

Built Scrapy-based data collection tools to gather and normalize part-number
data used by warehouse automation workflows.

**Tech:** Python • C# • pandas • pdfplumber • Scrapy • openpyxl

### 🐒 MONKEYTOOLS

Portable C# command-line toolbox containing utilities for networking,
diagnostics, automation, parsing, hashing, and developer tools.

Includes a recursive-descent expression parser with AST evaluation and
right-associative exponentiation.

**Tech:** C# • .NET

### 🔧 Reverse Engineering

Reverse engineered embedded firmware and proprietary devices, including
firmware extraction and asset analysis for the Jensen CAR710W.

Investigated VicoHome camera communication and contributed Go code while
working with authentication, WebRTC signaling, SDP, ICE, media tracks,
and local video access.

**Tech:** Go • WebRTC • Wireshark • ffmpeg • Linux

### 🔐 Privacy-Conscious Application Design

Building a digital waiver and ID capture system for an independent tattoo
artist, integrated with an existing Squarespace site.

The system is designed around data minimization and client-controlled
encryption so sensitive customer records can be stored and backed up without
giving the developer standing access to plaintext customer data.

**Tech:** JavaScript • HTML • CSS • Canvas API • Cloudflare

### 🏠 Homelab

Built lightweight APIs, dashboards, and automation for personal infrastructure
and self-hosted services.

**Tech:** FastAPI • Python • SQLite • Docker • Linux • Tailscale

### 📄 Document & Media Automation

Built tools for extracting useful information from obnoxious documents and
media, including PowerPoint-to-Markdown conversion and automated extraction of
web-based course instructions.

Built media-processing workflows using yt-dlp, ffmpeg, and Whisper to retrieve,
process, transcribe, and turn course media into searchable text.

Because clicking "Next" 47 times is not a feature.

**Tech:** Python • python-pptx • yt-dlp • ffmpeg • Whisper
